# Creating Your First Project

Learn how to set up your first Dembrane project and configure it for success.

## Step 1: Project Creation

1. Log in to your Dembrane account
2. Click "Create New Project" from the dashboard
3. Enter a project title
   - Choose something descriptive and recognizable
   - You can change this later if needed

## Project Settings

### Basic Configuration
- **Project Name**: Choose a clear, identifiable name
- **Context Description**: Add details about your project's purpose (internal use)
- **Language**: Select the primary language for transcription and analysis
  - This affects both the participant portal and AI analysis
  - Currently supports multiple European languages

### Privacy Settings
- Enable/disable participant tutorial
- Configure privacy statement visibility
- Set data retention policies

### Export Options
- Set up data export preferences
- Configure transcript formats
- Enable/disable specific data fields

## Project Organization

### Tags and Categories
- Create tags for different types of conversations
- Set up group discussion identifiers
- Organize individual entries

### Analysis Setup
- Configure AI transcription settings
- Add specific terms or abbreviations
- Include regional names for better recognition

## Best Practices

1. **Project Naming**
   - Use clear, descriptive names
   - Include date or version if relevant
   - Consider using prefixes for different project types

2. **Context Setting**
   - Document your research goals
   - Note any specific methodological requirements
   - List key stakeholders

3. **Privacy Configuration**
   - Review all privacy settings before launching
   - Ensure compliance with local regulations
   - Test participant experience
