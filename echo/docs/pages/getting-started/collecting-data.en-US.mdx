# Collecting Your First Data

Learn how to effectively collect and manage conversation data using Dembrane.

## Recording Sessions

### Preparation
1. **Environment Setup**
   - Choose a quiet location
   - Test internet connectivity
   - Prepare QR codes or links

2. **Participant Briefing**
   - Explain the process
   - Share privacy information
   - Set expectations

### Starting a Session
1. Participants scan QR code or use link
2. Complete tutorial (if enabled)
3. Begin recording
4. Monitor transcription in real-time

### Managing Recordings
- Pause/resume functionality
- Live transcript preview
- Audio quality indicators

## Best Practices

### Audio Quality
- **Environment**
  - Minimize background noise
  - Avoid echo-prone spaces
  - Consider room acoustics

- **Speaking Guidelines**
  - Clear enunciation
  - Moderate pace
  - One speaker at a time

### Session Management
- **Time Management**
  - Plan for 45-60 minute sessions
  - Include breaks for longer sessions
  - Allow time for questions

- **Group Dynamics**
  - Manage turn-taking
  - Encourage equal participation
  - Handle interruptions
