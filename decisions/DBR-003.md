# RFC: DBR-003 Branching + Staging Decision

## Author
Dat Tran

## Problem
We require multiple stages to stage changes. Ideally done via GitOps

## Proposed Solution
Deploy to production on branch "production". Deploy to dev on branch "dev".

## Details
All pipelines should be written to deploy "development" branch into "development" environment and "production" branch into "production" environment. 

## Alternatives
Cherrypicking for releases, etc. 

## Impact
Low; Easy to change this. But good start.
