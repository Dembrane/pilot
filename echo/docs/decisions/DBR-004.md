# RFC: DBR-004 Infrastructure Resource Naming convention

## Author
Dat Tran

## Problem
We need a naming convention for resources

## Proposed Solution
DBR-<environment>-<functionalScope>-<function>-<resourceType>-<optional: enumerator>
Example:

DBR-prod-CICD-TerraformBackend-StorageAccount
DBR-prod-Backend-Database-AzureSQLInstance-0
DBR-prod-Workers-CachingLayer-RedisCluster

## Details
Can be used to name Terraform objects and Azure resources

## Alternatives
- include region
- exclude function
- etc


## Impact
Low; Easy to change this. But a start.
