
# PDF Pilot




## Run Locally (Development)

### Recommended Option - Use the dev container
* Have docker installed (https://docs.docker.com/engine/install/)
* In VSCode, open the command palette(CMD+Shift+P) and "Reopen in Container)
* Add your env keys to `server/.env`
  ```
  cd server 
  cp .env.sample .env
  ```
* Run the server
  ```
  cd server
  pip install -r requirements.txt
  ./run.py
  ```
* Run the frontend
  ```
  cd frontend
  yarn
  yarn dev
  ```



## API Reference
OpenAPI docs are auto-generated by FastAPI 
http://localhost:8000/docs




## Running in Production

* Add your env keys to server/.env

* Install deps (both server and frontend)
```
cd frontend && yarn
cd ../server && pip install -r requirements.txt
```

* Generate frontend code and copy to server so it can be served from there
```
cd frontend
yarn build-and-copy
```

* Run server 
```
cd server
./prod.py
```
