# RFC: DBR-002 Usage of Terraform for IaC

## Author
Dat Tran

## Problem
We need a syntax to write infrastructure as code

## Proposed Solution
Terraform

## Details
TF is the most mature open source IaC language out there. Also happens to be the only IaC language with skills represented in the team. 
Some pitfalls with TF:
- Doesn't integrate into application code well ( in case you need to spin up infrastructure within the application processes themselves )

## Alternatives
Azure Biceps

## Impact
Low; however moving from TF would be a pain.
