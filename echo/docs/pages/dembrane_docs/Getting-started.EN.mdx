# Getting Started with Dembrane

## First Steps

1. Sign in to your Dembrane account
2. Click "Create New Project"
3. Enter a project title (you can modify this later)

## Initial Setup

### Portal Editor Basics
- Default language is English for the participant portal
- Each language setting generates a unique QR code
- Share project links for online participation
- Generate QR codes for in-person participant scanning

> **Note:** Remember to save/screenshot your QR codes!

### Quick Start Checklist
1. Configure basic project settings
2. Set up your participant portal
3. Create your first page
4. Share your QR code or link
5. Start your first recording

## Next Steps

After completing initial setup, you can:
- Customize your project settings
- Create participant pages
- Set up analysis parameters
- Begin data collection

See the [Core Aspects](./core-aspects) guide for detailed configuration options.
