# Setting Up Your Portal

The participant portal is your gateway to collecting conversations. Learn how to configure it for optimal engagement and data collection.

## Portal Configuration

### Language Settings
- Select primary interface language
- Configure transcription language
- Set up multilingual support if needed

### Tutorial Options
1. **Default Tutorial**
   - Basic introduction to the platform
   - Privacy information
   - Recording instructions

2. **Custom Tutorial**
   - Add specific instructions
   - Include project context
   - Customize privacy messages

### Welcome Page
- Add a custom title
- Include project description
- Set expectations for participants

### Thank You Page
- Customize completion message
- Add next steps if applicable
- Include contact information

## Access Methods

### QR Code
- **Generation**: Automatically created for each project
- **Usage**: Perfect for in-person sessions
- **Best Practices**:
  - Test QR code before sessions
  - Have backup direct links ready
  - Screenshot QR code for offline use

### Direct Links
- Share via email or messaging
- Embed in websites or documents
- Track link usage

## Privacy and Security

### Data Protection
- EU-based processing
- GDPR compliance
- Private Azure servers

### Participant Privacy
- Anonymous recording
- Clear consent process
- Data usage transparency

## Testing Your Portal

Before launching:
1. Test the participant flow
2. Verify all language settings
3. Check recording functionality
4. Review privacy statements
5. Test on different devices
